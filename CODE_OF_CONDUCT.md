# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, give and accept constructive feedback
gracefully, and focus on what is best for the project and its community.
Harassment and personal attacks are not tolerated.

To report unacceptable behavior, contact the maintainer privately through
their GitHub profile. Reports are handled confidentially.
